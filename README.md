# Feuille-de-calcul

Outils de calcul d'ingénieur civil (bureau IngPhi SA), en Python, selon les normes SIA.

| Dossier | Rôle |
|---|---|
| `Mur contre terre/` | Application principale : vérification d'un mur de sous-sol en béton armé (SIA 260/261/262/267). Voir son `README.md`. |
| `Retrait et armature minimale/` | Futur outil ; contient seulement les feuilles Excel source pour l'instant. |

La conversion des normes SIA en Markdown (pour un LLM local) vit dans le dépôt
[Normes_SIA_Artifact](https://github.com/damthon/Normes_SIA_Artifact).
